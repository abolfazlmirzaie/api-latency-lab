# Benchmarking

## Purpose

Benchmarking in API Latency Lab is the process of measuring API behavior under a
defined and reproducible workload.

The purpose is not to assume that an optimization is better.

The purpose is to collect measurements and use those measurements to understand
the effect of a specific change.

The project follows:

```text
Research
    ↓
Define Benchmark
    ↓
Prepare API
    ↓
Load Test
    ↓
Measure
    ↓
Analyze

Document
